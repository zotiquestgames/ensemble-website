# ensemble-website

Static site for [ensemble.zotiquestgames.com](https://ensemble.zotiquestgames.com),
the home of Ensemble, the fiction engine RPG for groups by Zotiquest Games.

- Plain HTML, CSS and JS, no build step. Hosted on Netlify: every push to
  `main` goes live. Work on a branch and open a pull request.
- Built from the template of `loner-website` (same structure, CSS and
  product card markup), with its own palette and texts.
- Pages and product data follow the Zotiquest catalog
  (`sites/ensemble-website.yml` in the catalog repo).
- This repo is public: commit only material that may be public.
